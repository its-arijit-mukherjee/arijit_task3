# arijit_task3

A simple CSS practice project demonstrating different ways to style HTML elements using **element selectors, classes, IDs, and pseudo-classes**.

### What I Practiced

* Styling elements using selectors
* Using `class` and `id`
* Styling specific text with `<mark>`
* Using `:first-child`, `:last-child`, and `:nth-child()`
* Connecting an external CSS file to HTML

### Tech Used

* HTML
* CSS

### How to Run

Open `index.html` in a browser.

This is a beginner-friendly CSS practice project.
